## 📖 Overview

Smart Traders AI is a modern agricultural marketplace built using **Spring Boot**, **React**, and **PostgreSQL**. It enables farmers to sell crops directly to traders and vendors, reducing dependency on middlemen.

The platform also includes an **AI Assistant** powered by **LangChain4j + Ollama (Mistral)** that answers user questions using Retrieval-Augmented Generation (RAG) based on real marketplace data.
